关于本站

About this site

本仓库是一份可部署到 GitHub Pages 的量子力学教材导览：总导航页列出常用教材，每一本另有独立介绍页。开放教材只链到作者或出版社官方源；商业教材只提供导读与正规购买、馆藏入口。

This repository is a GitHub Pages-ready guide to quantum-mechanics textbooks. The homepage is a catalog; each title has its own introduction page. Open works link to official hosts. Commercial titles receive a guide page and a publisher or library link.

为何不存放教材 PDF

Why the PDFs are not in the repo

Griffiths、Sakurai、Shankar、Cohen-Tannoudji、Dirac、Nielsen & Chuang 等书仍受版权保护。将 PDF 上传到 GitHub 构成侵权，并违反 GitHub 服务条款。

Major commercial textbooks remain in copyright. Uploading those PDFs to GitHub is infringement and breaks GitHub’s terms of service.

如何启用 GitHub Pages

Enable GitHub Pages

Settings → Pages → Deploy from a branch → main / (root)。数分钟后访问 https://xie-fan.github.io/quantum-physics-library/

Settings → Pages → Deploy from a branch → main / (root). Then open https://xie-fan.github.io/quantum-physics-library/
